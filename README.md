# Portfolio — Mohammad Hossein Salehy Nezhad

Cyberpunk / fluid portfolio with scroll motion.

**Live:** [mhsn2005.github.io/portfolio](https://mhsn2005.github.io/portfolio)  
(Enable GitHub Pages: Settings → Pages → `main` / root)

## Features
- Fluid canvas background (particles + soft blobs)
- Scroll-triggered reveal animations
- Cyberpunk aesthetic (Orbitron + cyan/magenta)
- Fully responsive + mobile menu
- Scanlines + noise overlay

## Stack
Pure HTML / CSS / vanilla JS — no build step.
