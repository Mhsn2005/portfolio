# Portfolio – Mohammad Hossein Salehy Nezhad

Modern personal portfolio website.

**Live:** [mhsn2005.github.io/portfolio](https://mhsn2005.github.io/portfolio) (enable GitHub Pages on `main` branch / root)

## Features
- Clean, modern design with dark / light mode
- Fully responsive
- Highlights full-stack skills (React, Angular, .NET, Clean Architecture)
- Selected project cards (without exposing private repos)

## Stack
- Pure HTML + CSS + vanilla JS (fast, no build step)
- Inter + JetBrains Mono fonts
- CSS custom properties for theming

## Local preview
Just open `index.html` in a browser or use any static server.
